# Radius, shadows and motion

## Radius

One base radius of 10px (`--radius`) and four steps derived from it, so a change to the base moves every corner together. The Tailwind `rounded-*` utilities map onto these steps through `theme.css`.

<RadiusScale />

## Shadows

The values are Tailwind's defaults, exposed as tokens so that a page without Tailwind can use the same elevation. Shadows are subtle and few: buttons and inputs get `sm`, floating surfaces get `lg`. Nothing else floats.

<ShadowScale />

## Motion

One easing and three durations. Hover changes use `fast`; anything that opens uses `base`; the one entrance animation, `fade-up`, uses `slow`. All of it is transform and opacity only, and `prefers-reduced-motion: reduce` sets every duration to zero and turns the animation off.
