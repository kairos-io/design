# Icons

The apps use [Lucide](https://lucide.dev) through `lucide-react`: one stroke weight, a 24-unit grid, and a name for most things an infrastructure tool needs (`Server`, `Package`, `Rocket`, `KeyRound`). The package depends on it and the components use it for their own icons (the loading spinner, the dialog close, the select chevron).

## Sizes

- 16px (`size-4`) inside buttons, inputs, sidebar items, badges and table cells. The `Button` sets this on any SVG child.
- 14px (`h-3.5 w-3.5`) for the info tooltip trigger and breadcrumb chevrons.
- 40px (`h-10 w-10`) for the empty-state illustration, in muted ink.

## Colour

Icons take `currentColor`. Next to text they inherit; alone in a tile they take a tone (`text-ok`) through the `toneText` map.

## Labelling

An icon next to text is decorative: `aria-hidden="true"`. An icon that is the whole control needs a name: `aria-label` on the button, not on the icon. `Button` warns in development when an icon-only size has no label.
