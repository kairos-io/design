# Spacing and layout

## The scale

A 4px base, the Tailwind scale. Components use the steps below; the ones the apps reach for most are 2 (8px) between controls, 4 (16px) inside a tile, 6 (24px) inside a card and between cards, and 8 (32px) for page padding.

<SpacingScale />

## Breakpoints

Min-width, mobile first. The apps make two decisions: below `md` the sidebar is a drawer behind a navy top bar, and from `lg` it shows its labels.

<Breakpoints />

The docs site uses Infima's 996px for its own navbar collapse; it is not part of this system.

## Page layout

- Content is padded 32px on desktop, 24px below `lg`, 16px below `md`, and capped at 1080px; the message and progress pages cap at 760px.
- A form field is capped at 640px so a text input never spans a wide screen.
- The review step is a two-column grid, editor and a 300px aside, that stacks below `lg`.
- A sticky footer with the step actions sits on a translucent, blurred bar above the content.
